Each method in java 8 stream API can be categorized into Intermediate, Terminal and Static Factory Methods,
Short-circuiting operations, primitive Stream specializations

A. Intermediate Operations (Return a new stream)
FMFDSSPLS
1. filter(Predicate<T>)
filters elements based on a condition

List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "David");
names.stream()
     .filter(name -> name.length() > 4)
     .forEach(System.out::println); // Output: Alice, Charlie, David

2. map(Function<T,R>)
transforms each element

List<Integer> numbers = Arrays.asList(1, 2, 3, 4);
numbers.stream()
       .map(n -> n * 2)
       .forEach(System.out::println); // Output: 2, 4, 6, 8

3. flatMap(Function <T, Stream<R>>)
Flattens nested collections into a single stream

List<List<String>> nestedList = Arrays.asList(
    Arrays.asList("A", "B"),
    Arrays.asList("C", "D")
);
nestedList.stream()
          .flatMap(Collection::stream) //List::stream
          .forEach(System.out::println); // Output: A, B, C, D

List<List<Integer>> list=Arrays.asList(Arrays.asList(1,2),Arrays.asList(3,4),Arrays.asList(5,6));
        List<Integer> flatten=list
                                .stream()
                                .flatMap(Collection::stream)
                                .collect(Collectors.toList());
        System.out.println(flatten);

4. distinct()
removes duplicate

List<Integer> numbers = Arrays.asList(1, 2, 2, 3, 4, 4);
numbers.stream()
       .distinct()
       .forEach(System.out::println); // Output: 1, 2, 3, 4 still maintains insertion order

Set<Integer> uniqueNums=numbers.stream()
                    .collect(Collectors.toSet()); //removes duplicate, but it does not maintain insertion order, more efficient as intermediate distinct is not used

5. sorted()
Sorts elements naturally
If the elements are comparable (like Integer, String etc) to sort elements in natural order

List<String> names = Arrays.asList("Bob", "Alice", "David");
names.stream()
     .sorted()
     .forEach(System.out::println); // Output: Alice, Bob, David

6. sorted(Comparator<T>)
sort element in a custom order other than natural order
Sorts using a custom comparator

List<String> names = Arrays.asList("Bob", "Alice", "David");
names.stream()
     .sorted((a, b) -> b.compareTo(a)) // Reverse order
     //.sorted((a,b)->b-a)
     //.sorted(Comparator.reverseOrder())
     .forEach(System.out::println); // Output: David, Bob, Alice

For custom class we can use Comparator.comparing
List<Employee> employees = Arrays.asList(
    new Employee("John", 25),
    new Employee("Alice", 30),
    new Employee("Bob", 20)
);
employees.stream()
         .sorted(Comparator.comparing(Employee::getAge))
         .forEach(e -> System.out.println(e.getName()));

Here Employee us a Custom class with fields name and age and sorting is done by age
If you want to sort objects based on one of their fields, but you do not want to write your own comparator manually
it simplifies the code and make it more readable.
If you want to do sorting in reverse order, you can do chaining the comparator with reversed()

employees.stream()
         .sorted(Comparator.comparing(Employee::getAge).reversed())  // Sort by age in reverse order
         .forEach(e -> System.out.println(e.getName() + ": " + e.getAge()));


Sorting by multiple fields (chaining comparators)
This will first sort by age and if two employees have the same age, it will sort them by their name.
employees.stream()
         .sorted(Comparator.comparing(Employee::getAge)
                           .thenComparing(Employee::getName))  // Sorting by age and name
         .forEach(e -> System.out.println(e.getName() + ": " + e.getAge()));


7. peek(Consumer<T>)
Debugging/logging without modifying the stream

List<Integer> numbers = Arrays.asList(1, 2, 3);
numbers.stream()
       .peek(n -> System.out.println("Before map: " + n))
       .map(n -> n * 2)
       .peek(n -> System.out.println("After map: " + n))
       .forEach(System.out::println);

8. limit (long n)
Limits the stream to the first n elements

List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
numbers.stream()
       .limit(3)
       .forEach(System.out::println); // Output: 1, 2, 3

9. skip(long n)
Skips the first n elements

List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
numbers.stream()
       .skip(2)
       .forEach(System.out::println); // Output: 3, 4, 5



B. Terminal Operations (Produce a result or side-effect)

1.  forEach(Consumer<T>)
performs an action on each element

List<String> names = Arrays.asList("Alice", "Bob");
names.stream().forEach(System.out::println); // Output: Alice, Bob

2. toArray()
converts stream into an array

List<String> names = Arrays.asList("Alice", "Bob");
String[] array = names.stream().toArray(String[]::new);
System.out.println(Arrays.toString(array)); // Output: [Alice, Bob]
String[] array = list.toArray(new String[0]); //specify the type
Object[] array = list.toArray(); // no type specified so Object array and need to type cast

3. reduce(BinaryOperator<T>)
Combines elements into a single result
List<Integer> numbers=List.of(1,2,3,4);
int sum=numbers.stream().reduce(0,Integer::sum);

4. collect(Collector<T,A,R>)
collects elements into a collection (eg list, set, map)

List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
List<String> filteredNames = names.stream()
                                 .filter(name -> name.length() > 3)
                                 .collect(Collectors.toList());
System.out.println(filteredNames); // Output: [Alice, Charlie]

5. min(Comparator<T>)
find the smallest element

List<Integer> numbers = Arrays.asList(5, 3, 8, 1);
Optional<Integer> min = numbers.stream().min(Integer::compareTo);
System.out.println(min.get()); // Output: 1

6. max(Comparator <T>)
find the largest element

List<Integer> numbers = Arrays.asList(5, 3, 8, 1);
Optional<Integer> max = numbers.stream().max(Integer::compareTo);
System.out.println(max.get()); // Output: 8

7. count()
Counts the number of elements
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
long count = names.stream().count();
System.out.println(count); // Output: 3

List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "David", "Eve");
long count = names.stream()
                  .filter(name -> name.startsWith("A"))
                  .count();
System.out.println("Names starting with 'A': " + count); //Names starting with 'A': 1

8. anyMatch(Predicate<T>)
Checks if any element matches the condition

List<Integer> numbers = Arrays.asList(1, 2, 3, 4);
boolean hasEven = numbers.stream().anyMatch(n -> n % 2 == 0);
System.out.println(hasEven); // Output: true

9. allMatch(Predicate<T>)
Checks if all elements match the condition

List<Integer> numbers = Arrays.asList(2, 4, 6, 8);
boolean allEven = numbers.stream().allMatch(n -> n % 2 == 0);
System.out.println(allEven); // Output: true

10. noneMatch(Predicate<T>)
Checks if no elements match the condition

List<Integer> numbers = Arrays.asList(1, 3, 5, 7);
boolean noneEven = numbers.stream().noneMatch(n -> n % 2 == 0);
System.out.println(noneEven); // Output: true

11. findFirst()
Returns the first element(if any)

List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
Optional<String> first = names.stream().findFirst();
System.out.println(first.get()); // Output: Alice can use ifPresent, orElse, orElseGet

12. findAny()
Returns any element no guarantee of specific element

List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
Optional<String> any = names.stream().findAny();
System.out.println(any.get()); // Output: Alice (or any other element)

Short-circuiting operations are a subset of terminal operations which allow for early termination of the the stream processing.
These operations can stop processing once a certain condition is met, without having to process the entire stream.
1. anyMatch
2. allMatch
3. noneMatch
4. findFirst
5. findAny
6. limit
7. skip
8. distinct: It can also short-circuit processing by stopping the need to process duplicate elements once unique elements have been found

limit, skip and distinct are intermediate but still short-circuiting and will cause the stream to be consumed when executed.
